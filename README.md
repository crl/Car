# 运管家 · Car

面向自有运输车辆的本地内账软件，以车牌为主要标识，记录运费收入、日常运营支出和运输路线，查看单车及整体收支情况。适合单人本机使用，桌面优先并兼顾手机布局。

## 桌面版开发与构建

桌面版使用 Tauri 2，应用标识为 `com.crl.car`。前端由 Vite 构建，业务和 SQLite 读写在 Rust 中通过 `rusqlite` 执行；安装包包含前端资源，不部署 Python，也不需要运行本地 HTTP 服务。

开发环境需要 Node.js 24、npm、Rust stable（至少 1.90）及对应平台的 Tauri 2 系统构建依赖。macOS 14 或以上，需要 Xcode Command Line Tools；Windows 需要 MSVC C++ 构建工具和 WebView2。

```bash
npm ci
npm run desktop:dev
```

`desktop:dev` 启动 Tauri 桌面窗口，并通过 Vite 在 `127.0.0.1:1420` 提供开发资源；该端口仅用于开发。单独运行 `npm run dev` 只启动前端开发服务器，不能替代桌面后端。

```bash
npm run desktop:build
```

构建结果位于 `src-tauri/target/release/bundle/`。`npm run build` 仅构建前端资源。首次打开桌面版时，选择创建空账本或通过原生文件选择框导入已有 SQLite 账本；不会自动使用仓库根目录的 `cars.db`。

## 功能概览

| 页面 | 路径 | 功能 |
| --- | --- | --- |
| 车辆管理 | `#/cars`（默认首页） | 新增、编辑和搜索车辆；查看各车累计收入、支出、差额 |
| 单车详情 | `#/cars/车辆ID` | 车辆资料、逐笔收支、日期筛选、项目组合筛选、日期排序、筛选合计和 Excel 导出 |
| 收支账目 | `#/entries` | 登记与编辑收支，多列组合筛选及导出当前明细 |
| 收支类型 | `#/categories` | 新增、修改、停用类型，并设置是否必须填写路线 |
| 地址管理 | `#/addresses` | 浏览行政区划树、搜索地区、维护常用地区 |

### 车辆与记账

- 车牌为必填项，车架号和备注为选填项；历史车型资料保留兼容。
- 点击车辆列表的车牌进入该车详情，可直接为该车记账。
- 收入预设为运费；支出预设为油费、通行费、倒板费、工资，可自行维护类型。
- 每笔记录包含日期、车辆、收支方向、项目、金额、起终点、往来方和备注。
- 金额必须大于零，最多两位小数；数据库以整数分存储。
- 保存中防止重复点击，失败保留输入；有未保存修改时，退出表单会提示。

### 查询、排序与汇总

- 单车详情的“项目”表头可打开多选筛选，支持单项或组合；“全部项目”可切换全选与全部取消。
- 点击“日期”表头切换由早到晚、由晚到早；项目筛选可与日期条件叠加。
- 顶部显示该车全期累计金额，明细及底部合计显示当前筛选口径。
- 收入用绿色和正号表示，支出用橙色和负号表示；差额正数绿色、负数橙色、零值灰色。
- **收支差额 = 已登记收入 − 已登记支出**，不等同于会计利润；本版未实现应收应付、折旧或完整财务核算。

### Excel 导出

- 输出真正的 `.xlsx` 文件，不是改扩展名的 CSV。
- 单车详情“导出当前明细”沿用当前筛选及排序；没有数据时提示，不生成空文件。
- 收支账目页和车辆页均可导出当前筛选范围内的明细；分页不缩小导出范围。
- 收入与支出使用独立金额列，并以绿色、橙色底色区分；附收入合计、支出合计和差额。
- 工作簿包含列标题、冻结首行、自动筛选和金额数字格式。

### 行政区划与运输路线

- 省、市、区县、乡镇/街道以树状结构展开与折叠；搜索结果可定位并展开完整上级路径。
- 路线可选择到城市、区县或乡镇，不强制选到底；支持交换起终点。
- 从基础库选择的地区可以保存到常用地区，支持修改或移除常用，基础库保持只读。
- 运费默认路线必填，其他类型默认选填；如填写路线，必须同时提供起点和终点，允许起终点相同。
- 账目保留登记时的类型名称和地址快照，之后改名或停用不会修改历史路线；旧记录无路线时显示“未记录”。

**数据范围：**基础库截至 **2023-06-30**，覆盖大陆31个省级地区、342个地级节点、2,978个区县和41,352个乡镇/街道节点；不含港澳台，不代表当前最新全国完整区划。

来源：[Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)。数据来源说明和上游许可分别见 [data/README.md](data/README.md)、[data/REGIONS-LICENSE](data/REGIONS-LICENSE)。

## 技术结构

| 文件或目录 | 用途 |
| --- | --- |
| `src-tauri/src/main.rs` | Tauri 命令、原生对话框、应用生命周期 |
| `src-tauri/src/ledger.rs` | Rust 账本业务、SQLite 升级与备份还原 |
| `src-tauri/src/regions.rs` | 离线区划查询与搜索 |
| `src-tauri/src/export.rs` | 使用 `rust_xlsxwriter` 生成 Excel 工作簿 |
| `desktop.js` | 前端与 Tauri 命令桥接、启动与退出流程 |
| `app.js`、`index.html`、`style.css` | 页面、表单、筛选与交互 |
| `data/` | 离线行政区划数据及许可 |
| `.github/workflows/` | 桌面版测试、构建及产物上传 |

根目录的 `app.py`、`regions.py`、`excel_export.py` 及相关 Python 测试保留为旧版参考和迁移回归依据，不进入桌面运行链路。旧版 HTTP 接口不是桌面版部署方式。

## 数据保存与备份

- 桌面账本为系统应用数据目录（应用标识 `com.crl.car`）中的 `cars.db`，关闭应用或升级程序后保留。设置中展示实际账本路径、默认路径和自动备份目录。
- 开发调试可用 `CAR_DESKTOP_DATA_DIR` 指定独立数据目录；此覆盖仅在 debug 构建中生效。旧版 `CAR_DB` 不控制桌面版路径。
- 备份与还原使用原生保存／打开文件对话框。备份包含车辆、收支、类型和常用地区，不包含程序或全国区划基础库。
- 还原会替换当前账本，需确认并校验文件；还原前在账本目录的 `backups/` 中保存原账本。单个还原文件最大 **50MB**。
- Excel 导出通过原生保存对话框选择位置；取消操作不会保存文件。
- `.gitignore` 排除账本、临时数据库文件和备份。**仓库及安装包不包含本机车辆、账目或模拟记录**，新建账本从空车辆、空账目开始。

## 测试与平台验证状态

```bash
npm test
cargo test --locked --manifest-path src-tauri/Cargo.toml
```

前端测试检查桌面桥接与相关交互约定；Rust 测试用于账本和导出等后端行为。旧版回归测试可独立执行：

```bash
python3 -B -m unittest discover -s tests -v
```

旧版测试通过不代表桌面版或原生窗口已经验证。当前 Intel macOS 的本机桌面测试仍待完成；**Windows 界面必须在真实 Windows 环境验证，目前未验证**。安装、原生对话框、中文显示、退出提示、备份还原及导出仍需对应平台实测。

CI 配置覆盖 macOS Apple Silicon、macOS Intel 和 Windows x64，运行测试并构建 `.dmg`／NSIS `.exe`，仅上传 workflow artifacts；配置存在不代表本次构建已成功，也不自动创建 GitHub Release。当前不配置代码签名、签名公证或自动更新。

## 当前使用边界

本版面向单人本机离线使用，不提供账户权限、多人协作、云端存储或跨设备同步。前端保留响应式布局，但桌面安装包并非手机端产品。收支差额仅反映已登记收支，不替代完整财务核算。
