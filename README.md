# 汽车内账

本地单人使用版本，Python 3，无需安装第三方依赖。

## 启动

在项目目录执行：

```bash
python3 app.py
```

浏览器打开 http://127.0.0.1:8765 。终端按 Ctrl+C 停止。

## 功能

- 录入和编辑车型、车牌、车架号与备注，搜索车辆。
- 按车辆登记收入和支出，金额精确到分。
- 按车辆、日期查询账目，查看累计及筛选汇总。
- 导出全部账目 CSV，可用 Excel 打开。

数据在项目目录的 cars.db 中，重启保留。备份时先停止服务，再复制该文件；恢复时停止服务后用备份替换。本版仅监听本机，不支持多人同步或账户权限。

收支差额是现金收支差额；应收应付、车辆库存成本及利润口径尚待确认。车辆录入及收支登记已完成浏览器验收。

## 自有车辆业务

收入预设运费，支出预设油费、通行费、倒板费、工资。在导航中进入「收支类型管理」可新增、修改、删除类型。删除采用停用方式，历史账目保留原类型名称；新增同名类型可恢复使用。记账时收入和支出类型自动联动。

已通过浏览器验证车辆录入、油费和运费登记、单车及总账差额、刷新后记录保留。数据库独立测试覆盖类型新增、修改、停用、恢复、历史账目保留及无效金额拒绝。运行 `python3 -B -m unittest discover -s tests -v` 复查。

当前数据库包含明确标注的验收示例车辆及两笔示例账目（运费 1000 元、油费 200 元），不属于实际经营数据。

## 路线和地址管理

导航「地址管理」支持名称、详细地址的新增、搜索、修改和删除。记账时分别在起点、终点输入关键词，从公共地址候选列表选择；可在新窗口管理地址，再点击「刷新地址列表」。地址名称不能与在用地址重名。

运费默认要求路线，工资等其他类型默认选填。在「收支类型管理」编辑类型时可勾选「路线必填」，类型改名后规则仍保留。选填路线如填写一端，也须补齐另一端；允许起终点相同。

历史账目保存登记时的完整地址，地址修改或删除不会改变历史记录或导出内容。旧账目路线显示「未记录」。启动服务时自动升级数据库，保留已有记录。

本次浏览器验收新增了一个标注为示例的仓库地址，以及测试车辆上的两笔 1 元账目（运费、工资）。均为验收示例，不是实际经营数据。

## 界面改版

采用左侧导航与浅色商务布局，手机自动切换紧凑导航和卡片列表。记账弹窗按基本信息、金额与类型、运输路线、补充信息分组；保存按钮固定在底部。地址支持关键词搜索、上下方向键及回车选择、交换起终点，并可在记账弹窗内新增地址，返回后保留原输入。

新增清空筛选、字段错误提示、保存状态、成功提示和未保存退出确认。样式和脚本拆分为 style.css、app.js，数据库与现有业务接口保持兼容。隔离账本浏览器验收覆盖车辆新增、收入切换、金额与备注保留、内嵌地址新增、路线必填提示、键盘选址、保存及刷新；验证了 1440、1024、390 像素布局无整页横向溢出，手机保存按钮保持可见。服务中断时输入保留，保存按钮恢复可用。

当前正式账本按用户要求新增五辆模拟运输车辆，编号「模拟车辆-001」至「模拟车辆-005」，未为它们生成收支。

## 单车收支详情

车辆列表的车型、车牌及「查看明细」均可进入 `/cars/车辆ID`，查看该车资料、累计收支与逐笔账目。日期筛选只影响明细和筛选小计；顶部累计金额保持全期口径。支持清空筛选、返回车辆列表、直接打开及刷新。详情页记账默认选中当前车辆，保存后更新汇总。

浏览器使用隔离数据库验证了车辆关联、日期筛选、清空筛选、详情页记账及刷新保存、无账目车辆和不存在车辆提示；390 像素布局无整页横向溢出。实际账本未新增验收记录。

## 行政区划与常用地区

地址管理分为只读行政区划基础库及可维护的常用地区。支持省、市、区县、乡镇街道逐级浏览，或用空格分隔上级地区关键词搜索；可选择城市、区县、乡镇街道，不要求选到最底层。记账选择地区后自动保存到常用地区，支持修改和移除常用，历史快照保持原样。旧自定义地址保留兼容。

当前基础库为2023-06-30版本，覆盖大陆31个省级地区，不含港澳台；并非2026年最新全国完整区划。来源与许可详见 data/README.md 和 data/REGIONS-LICENSE。
