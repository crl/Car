# 汽车内账 · Car

面向自有运输车辆的本地内账软件，以车牌为主要标识，记录运费收入、日常运营支出和运输路线，查看单车及整体收支情况。适合单人本机使用，桌面优先并兼顾手机布局。

## 快速启动

需要 Python 3.9 或以上版本，无需安装第三方依赖。

```bash
git clone https://github.com/crl/Car.git
cd Car
python3 app.py
```

打开 [本地应用](http://127.0.0.1:8765/)，按 `Ctrl+C` 停止服务。首次启动自动创建 SQLite 数据库、预设收支类型；后续启动自动补充所需数据库字段。

## 功能概览

| 页面 | 路径 | 功能 |
| --- | --- | --- |
| 车辆管理 | `/cars`（首页 `/` 同样显示车辆页） | 新增、编辑和搜索车辆；查看各车累计收入、支出、差额 |
| 单车详情 | `/cars/车辆ID` | 车辆资料、逐笔收支、日期筛选、项目组合筛选、日期排序、筛选合计和 Excel 导出 |
| 收支账目 | `/entries` | 登记收入与支出，按车辆和日期筛选，导出全部账目 |
| 收支类型 | `/categories` | 新增、修改、停用类型，并设置是否必须填写路线 |
| 地址管理 | `/addresses` | 浏览行政区划树、搜索地区、维护常用地区 |

### 车辆与记账

- 车牌为必填项，车架号和备注为选填项；历史车型资料保留兼容。
- 点击车辆列表的车牌进入该车详情，可直接为该车记账。
- 收入预设为运费；支出预设为油费、通行费、倒板费、工资，可自行维护类型。
- 每笔记录包含日期、车辆、收支方向、项目、金额、起终点、往来方和备注。
- 金额必须大于零，最多两位小数；数据库以整数分存储。
- 保存中防止重复点击，失败保留输入；有未保存修改时，退出表单会提示。

### 查询、排序与汇总

- 单车详情的“项目”表头可打开多选筛选，支持单项或组合；“全部项目”可切换全选与全部取消。
- 点击“日期”表头切换由早到晚、由晚到早；项目筛选可与日期条件叠加。
- 顶部显示该车全期累计金额，明细及底部合计显示当前筛选口径。
- 收入用绿色和正号表示，支出用橙色和负号表示；差额正数绿色、负数橙色、零值灰色。
- **收支差额 = 已登记收入 − 已登记支出**，不等同于会计利润；本版未实现应收应付、折旧或完整财务核算。

### Excel 导出

- 输出真正的 `.xlsx` 文件，不是改扩展名的 CSV。
- 单车详情“导出当前明细”沿用当前筛选及排序；没有数据时提示，不生成空文件。
- 收支账目页面“导出全部账目”导出所有车辆账目，不按页面筛选缩小范围。
- 收入与支出使用独立金额列，并以绿色、橙色底色区分；附收入合计、支出合计和差额。
- 工作簿包含列标题、冻结首行、自动筛选和金额数字格式。

### 行政区划与运输路线

- 省、市、区县、乡镇/街道以树状结构展开与折叠；搜索结果可定位并展开完整上级路径。
- 路线可选择到城市、区县或乡镇，不强制选到底；支持交换起终点。
- 从基础库选择的地区可以保存到常用地区，支持修改或移除常用，基础库保持只读。
- 运费默认路线必填，其他类型默认选填；如填写路线，必须同时提供起点和终点，允许起终点相同。
- 账目保留登记时的类型名称和地址快照，之后改名或停用不会修改历史路线；旧记录无路线时显示“未记录”。

**数据范围：**基础库截至 **2023-06-30**，覆盖大陆31个省级地区、342个地级节点、2,978个区县和41,352个乡镇/街道节点；不含港澳台，不代表当前最新全国完整区划。

来源：[Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)。数据来源说明和上游许可分别见 [data/README.md](data/README.md)、[data/REGIONS-LICENSE](data/REGIONS-LICENSE)。

## 技术结构

后端使用 Python 标准库 HTTP 服务和 SQLite；前端使用原生 HTML、CSS、JavaScript，无前端构建步骤。Excel 导出使用标准库生成 OOXML 工作簿。

```text
app.py                本地 HTTP 服务、业务接口与数据库升级
app.js                页面、表单、筛选、排序与交互
index.html            页面入口与公共弹窗
style.css             桌面及手机样式
regions.py            区划索引、层级查询与搜索
excel_export.py       Excel 工作簿生成
data/                 离线行政区划数据及许可
tests/                业务回归测试
```

主要接口：`GET /api/data`、`GET /api/regions`、`GET /api/export`（Excel 全量导出）、`POST /api/export/xlsx`（按记录 ID 列表导出），以及车辆、类型和常用地区的保存接口。

## 数据保存与备份

- 默认账本为项目目录下的 `cars.db`，关闭页面或重启服务后保留。
- 需要其他账本时，可设置 `CAR_DB` 为数据库文件路径。
- 手动备份：停止服务，复制 `cars.db`；恢复时停止服务，再用备份替换。
- `.gitignore` 排除数据库、数据库临时文件、`backups/` 和 Python 缓存。**GitHub 仓库仅保存代码及基础区划数据，不包含本机车辆、账目、备份。**
- 本机账本曾按需录入明确标注的模拟记录；它们并未打包进仓库，新克隆的项目从空车辆、空账目开始。

## 测试

```bash
python3 -B -m unittest discover -s tests -v
```

自动化测试覆盖车牌必填、历史车型兼容、金额校验、收支类型维护、区划选择、路线必填、历史快照、Excel 导出及旧数据库升级。测试使用临时数据库，不修改日常账本。

## 当前使用边界

服务仅监听 `127.0.0.1:8765`，不提供账户权限、多人同步、云端存储或公网部署能力。手机布局已适配，但默认监听地址只允许当前电脑访问；跨设备访问需要另行设计网络和身份认证方案。
